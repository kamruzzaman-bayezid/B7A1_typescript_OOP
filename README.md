# TypeScript & OOP Assignment

এই প্রজেক্টটি TypeScript এবং Object-Oriented Programming (OOP) এর বিভিন্ন গুরুত্বপূর্ণ কনসেপ্টের ওপর ভিত্তি করে তৈরি করা হয়েছে। এখানে কোডিং প্রবলেম সলভ করার পাশাপাশি টাইপ সেফটি এবং আর্কিটেকচার নিয়ে দুটি টেকনিক্যাল ব্লগ রয়েছে।

## প্রজেক্ট স্ট্রাকচার

- **solutions.ts**: এখানে মোট ৭টি কোডিং সমস্যার সমাধান দেওয়া হয়েছে (Filter, Reverse String, Type Guard, Generics, Interface, Class/Inheritance, এবং Intersection)।
- **blog-1.md**: এখানে `any` টাইপের বদলে কেন `unknown` ব্যবহার করা নিরাপদ, তা নিয়ে বিস্তারিত আলোচনা করা হয়েছে।
- **blog-2.md**: এখানে OOP-এর চারটি মূল পিলার (Inheritance, Polymorphism, Abstraction, Encapsulation) নিয়ে কোডসহ উদাহরণ দেওয়া হয়েছে।

## কীভাবে রান করবেন

১. প্রথমে আপনার পিসিতে Node.js এবং TypeScript ইন্সটল থাকতে হবে।

২. ফাইলগুলো ক্লোন বা ডাউনলোড করুন।

৩. কোড চেক করার জন্য নিচের কমান্ডটি ব্যবহার করতে পারেন:
   ```bash
   npx tsx solutions.ts
```
> নোট: কোড রান করার জন্য আপনার পিসিতে Node.js ইন্সটল থাকতে হবে। `npx tsx` কমান্ডটি ব্যবহারের সময় যদি কোনো প্যাকেজ ইন্সটল করার পারমিশন চায়, তবে `y` দিয়ে এগিয়ে যান।
